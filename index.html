Dalam Pengembangan

Alur Kerja Analisis

Sistem ini disusun untuk membantu alur analisis data hujan dan informasi drainase secara bertahap.

1

Pilih stasiun hujan acuan.

2

Lihat data hujan maksimum tahunan.

3

Lakukan uji kualitas data hujan.

4

Hitung hujan rencana.

5

Tampilkan jaringan drainase pada WebGIS.

6

Cetak laporan atau gunakan peta sebaran hujan.

Fitur yang Tersedia

Beberapa fitur utama yang sudah disiapkan pada sistem ini.

✓ WebGIS jaringan drainase
✓ Basemap satelit dan peta jalan
✓ Data hujan maksimum tahunan
✓ Grafik hujan tahunan
✓ Uji kualitas data hujan
✓ Laporan PDF dan Word
✓ Kalkulator hujan rencana
✓ Overlay peta sebaran hujan

Panduan Singkat

Gunakan sistem ini sesuai kebutuhan analisis.

  1. Buka menu Data Hujan Tahunan untuk melihat grafik dan uji statistik.
  2. Buka menu Peta WebGIS Drainase untuk melihat saluran dan stasiun hujan.
  3. Buka menu Peta Sebaran Hujan untuk menampilkan overlay peta hujan BMKG.
  4. Gunakan laporan PDF/Word sebagai keluaran analisis kualitas data hujan.
